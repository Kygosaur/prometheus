# Example Welding Safety SOP

This file contains demonstration data only and must be replaced with an approved
organization-specific SOP before operational use.

Before welding, the assigned worker must wear a welding helmet with an appropriate
filter lens, flame-resistant gloves, protective clothing, and safety footwear.
Inspect the work area and remove combustible material before work begins.

Report damaged protective equipment to the supervisor and do not start the task
until a suitable replacement is available.
